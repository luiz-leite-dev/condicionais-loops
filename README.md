
# Python: Condicionais e Laços de Repetição

Repositório com exemplos práticos de Python utilizados em uma aula de 15 minutos sobre lógica de programação.

## Objetivo

Demonstrar como utilizar estruturas condicionais e laços de repetição para resolver problemas práticos.

## Conteúdo

1. Estruturas condicionais: `if`, `elif` e `else`.
2. Operadores relacionais e lógicos.
3. Laço de repetição `for`.
4. Laço de repetição `while`.
5. Aplicação prática: classificação de notas.

## Pré-requisitos

- Python 3 instalado.
- Visual Studio Code.
- Terminal integrado do VSCode.

## Como executar

Abra o terminal na pasta do projeto e execute:

```bash
python3 --version
python3 01_condicionais.py
python3 02_operadores_logicos.py
python3 03_laco_for.py
python3 04_laco_while.py
python3 05_classificacao_notas.py
```

Execute um arquivo por vez.
